# ✨ Overview

FlowState is a futuristic AI-inspired productivity operating system built using the MERN Stack.

Designed with immersive UI/UX, deep focus workflows, task intelligence, realtime productivity tracking, and modern glassmorphism aesthetics, FlowState transforms traditional task management into a next-generation focus experience.

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/MAKRAND-CODES/flowstate-todo.git
```

---

## 2️⃣ Install Frontend Dependencies

```bash
cd frontend
npm install
```

---

## 3️⃣ Install Backend Dependencies

```bash
cd backend
npm install
```

---

# 🔑 Environment Variables

Create `.env` inside backend:

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
PORT=5000
```

Create `.env` inside frontend:

```env
VITE_API_URL=http://localhost:5000/api
```

---

# ▶️ Run Development Server

## Backend

```bash
npm run server
```

## Frontend

```bash
npm run dev
```
